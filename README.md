# 舒尔特专注力训练小程序

基于腾讯云 CloudBase 开发的微信小程序，提供7种专注力训练模式。

## 功能特性

### 训练模式（7种）
1. **经典模式** - 数字正序点击
2. **干扰模式** - 彩色背景抗干扰训练
3. **换位模式** - 正确后全局重排
4. **倒序模式** - 从大到小倒序点击
5. **奇偶模式** - 按方格总数生成连续奇数或偶数
6. **挑战模式** - 每步限时2秒
7. **记忆模式** - 记忆后隐藏数字

### 难度等级（8级）
- 3×3 基础、4×4 初阶、5×5 高阶、6×6 超凡
- 7×7 绝世、8×8 无双、9×9 九天、10×10 疯狂

### 核心功能
- 难度解锁：完成当前难度后自动解锁下一难度
- 工具开关：隐藏数字、标记数字、提示
- 正确率统计：按不重复错误值计算
- 闯关模式：从5×5开始，每阶完成10局，依次挑战到10×10
- 训练记录：本地存储 + 云端同步
- 个人中心：统计、历史记录、设置

## 数据库集合

需要在 CloudBase 控制台创建以下集合：
1. `users` - 用户表
2. `train_records` - 训练记录表
3. `level_progress` - 难度解锁进度表
4. `pass_progress` - 闯关模式进度表

详见 DATABASE.md
