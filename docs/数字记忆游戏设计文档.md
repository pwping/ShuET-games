# 数字记忆 (Digital Memory) — 游戏设计技术文档

## 1. 游戏概述

**数字记忆** 是一款专注力与短时记忆训练游戏，作为「智趣训练」小程序的第 5 款游戏。

### 核心玩法

在 7×7 棋盘上，系统在随机位置显示 N 个数字（从 **3** 开始），玩家记忆后数字隐藏，需按 **1→2→3→...→N** 的顺序点击对应位置。点错则本关重置，全对则进入下一关（N+1），直到 **N=49（棋盘全满）通关**。

| 属性 | 值 |
|------|----|
| 棋盘规格 | 7 × 7（49 格） |
| 起始数字数 | 3 |
| 最终数字数 | 49 |
| 总关卡数 | 47（3 → 49） |
| 游戏类型 | 位置记忆 + 顺序回忆 |

### 与现有游戏风格统一

- 子包命名：`memoryGame`（小驼峰，与 `huarongDao`、`movingBlocks` 一致）
- 页面结构：`level → game → result`（3 页，与 `movingBlocks`、`sudoku` 一致）
- 数据流：本地缓存 + 云端云函数双写（与所有游戏一致）
- 设置：注册 `mg_settings` 键（与 `sd_settings`、`mb_settings` 等一致）

### 2.2 导航流

```
首页卡片点击
    ↓
memoryGame/level/level        ← 显示关卡进度（当前最大已通关数）
    ↓ 点击"开始"或关卡
memoryGame/game/game?level=N  ← N = 3~49
    ↓ 过关
memoryGame/result/result?level=N&time=...&errors=...
    ↓ "再玩一次" → navigateBack + game.onRestart() 重置本关
    ↓ "下一关"   → navigateBack + game.onNextLevel() 加载 N+1
    ↓ "查看记录" → navigateTo /pages/history/history
```

#### result → game 的通信模式（复用 movingBlocks 方案）

```javascript
// result.js
onRetry() {
  const pages = getCurrentPages();
  const prev = pages[pages.length - 2]; // game 页
  prev.onRestart();   // game 页定义的方法
  wx.navigateBack();
}
onNext() {
  const pages = getCurrentPages();
  const prev = pages[pages.length - 2];
  prev.onNextLevel(); // game 页加载下一关
  wx.navigateBack();
}
```

## 3. 数据模型

### 3.1 云数据库集合

**集合名**：`memoryGame_records`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动生成 |
| `openid` | string | 用户标识 |
| `level` | number | 闯到的数字数（3~49） |
| `time` | number | 本关用时（秒） |
| `errors` | number | 本关错误点击次数 |
| `status` | string | 固定 `"success"` |
| `createTime` | string | ISO 时间戳 |

**索引**：`openid` + `createTime`（复合降序，与 `train_records` 一致）

### 3.2 本地存储

| Key | 用途 | 数据结构 |
|-----|------|---------|
| `mg_settings` | 音效/震动设置 | `{ sound: bool, vibration: bool }` |
| `mg_records` | 本地缓存记录 | `[{ level, time, errors, status, createTime }]` |
| `mg_completed` | 已通关关卡 | `{ "3": true, "4": true, ... }` |

`mg_records` 缓存上限 200 条（与现有游戏一致），登录后同步到云端后清除本地。

### 3.3 云函数

#### `saveMemoryGameRecord`（保存记录）

```
入参：{ level, time, errors, createTime? }
逻辑：
  1. 获取 openid，未登录 → 401
  2. 写入 memoryGame_records 集合
  3. 返回 { code: 200, _id, createTime }
```

#### `getMemoryGameRecords`（查询记录）

```
入参：{ level?, limit?, stats? }
逻辑：
  if stats == true:
    - 查询当前用户已通关的最大 level（按 level 降序取 1 条）
    - 查询总通关次数
    - 返回 { code: 200, stats: { maxCompleted, totalCount } }
  else:
    - 按 createTime 降序返回记录列表
    - 返回 { code: 200, data: [...] }
```

与 `getSudokuRecords`、`getMovingBlockRecords` 的 stats 模式完全一致。

## 4. 游戏核心逻辑

### 4.1 level 页（进度选择）

**功能**：显示玩家闯关进度，提供进入游戏的入口。

```
数据结构：
  - maxLevel: number        ← 当前可挑战的最高关卡（3~49）
  - completedSet: object    ← { "3": true, ... }
  - allLevels: array        ← [3, 4, 5, ..., 49]

onLoad:
  1. 从 wx.getStorageSync('mg_completed') 读取本地进度
  2. 异步调用 getMemoryGameRecords({ stats: true })
  3. 合并本地和云端进度，更新 maxLevel
  4. 渲染关卡列表

关卡列表渲染：
  - maxLevel 以下的关卡：显示"可挑战"（绿色状态）
  - maxLevel 以上的关卡：显示锁定图标
  - 已通关的关卡：显示✅标记

导航：
  - 点击可挑战关卡 → navigateTo /game/game?level=N
  - 点击锁定关卡 → 不响应或提示
```

### 4.2 game 页（核心玩法）

```
data = {
  level: number,            // 当前关 N（3~49）
  GRID_SIZE: 7,
  TOTAL_CELLS: 49,
  phase: 'show' | 'playing' | 'won' | 'failed',
  positions: [{ num, row, col }],  // 数字位置
  cells: [{ num, hidden, matchState }],  // 49 格渲染数据
  nextExpected: number,     // 下一个应点的数字
  errors: number,           // 本关错误次数
  timerText: string,
  isTimerRunning: boolean,
  settings: { sound, vibration }
}
```

#### 游戏循环

```
initLevel(N):
  // 1. 生成 N 个随机不重复位置
  chosen = shuffle([0..48]).slice(0, N)
  positions = chosen.map((idx, i) => ({
    num: i + 1,
    row: Math.floor(idx / 7),
    col: idx % 7
  }))

  // 2. 初始化 cells
  cells = 49 格，每格 num=0, hidden=true
  positions.forEach(p => {
    cells[p.row * 7 + p.col] = { num: p.num, hidden: false, matchState: '' }
  })

  // 3. 进入显示阶段
  phase = 'show', nextExpected = 1, errors = 0

  // 4. 启动计时（从点击"开始"后才真正记时，但提前创建 timer 对象）

onStartTap():         // 玩家点"开始挑战"
  if phase != 'show': return
  cells.forEach(c => c.hidden = true)   // 隐藏所有数字
  phase = 'playing'
  startTimer()

onCellTap(e):
  if phase != 'playing': return
  const { row, col } = e.currentTarget.dataset
  const idx = row * 7 + col
  const cell = cells[idx]
  if !cell.hidden: return     // 已点过
  if cell.num === 0: return   // 空格

  if cell.num === nextExpected:
    // ✅ 正确
    cell.hidden = false
    cell.matchState = 'correct'
    playCorrectSound()
    nextExpected++

    if nextExpected > level:
      // 🎉 过关！
      phase = 'won'
      stopTimer()
      playVictorySound()
      saveRecord()
      setTimeout(navigateToResult, 800)
  else:
    // ❌ 错误
    errors++
    cell.hidden = false
    cell.matchState = 'wrong'
    playWrongSound()
    vibrate()

    // 显示所有数字供重新记忆
    phase = 'failed'
    cells.forEach(c => {
      c.hidden = false
      c.matchState = ''
    })

    setTimeout(() => {
      // 再次隐藏，进入 playing 阶段
      cells.forEach(c => c.hidden = true)
      nextExpected = 1
      phase = 'playing'
    }, 2000)
```

#### 计时器

```
startTime = Date.now()
interval = setInterval(100ms):
  elapsed = (Date.now() - startTime) / 1000
  timerText = elapsed.toFixed(1)

stopTimer():
  clearInterval(interval)
  return elapsed  // 秒
```

#### 记录保存

```
saveRecord():
  elapsed = stopTimer()
  rec = { level, time: elapsed, errors, status: 'success', createTime: new Date().toISOString() }

  // 本地缓存
  records = wx.getStorageSync('mg_records') || []
  records.unshift(rec)
  wx.setStorageSync('mg_records', records.slice(0, 200))

  // 更新关卡进度
  completed = wx.getStorageSync('mg_completed') || {}
  completed[String(level)] = true
  wx.setStorageSync('mg_completed', completed)

  // 云端同步（登录时）
  if app.globalData.isLoggedIn:
    wx.cloud.callFunction({ name: 'saveMemoryGameRecord', data: rec })
    wx.removeStorageSync('mg_records')
```

#### onRestart / onNextLevel（从 result 页调用）

```
onRestart():
  initLevel(this.data.level)  // 重新玩本关

onNextLevel():
  nextLevel = this.data.level + 1
  if nextLevel > 49:
    showToast('🎉 恭喜通关全部关卡！')
    return
  initLevel(nextLevel)
```

### 4.3 棋盘渲染（WXML）

使用 flat 数组 + 计算类名，避免 WXML 中 `Math.floor` 计算：

```html
<view class="board">
  <view wx:for="{{cells}}" wx:for-index="idx" wx:key="idx"
        class="cell {{item.hidden ? 'hidden' : ''}} {{item.matchState}}"
        data-row="{{computedRows[idx]}}" data-col="{{computedCols[idx]}}"
        bindtap="onCellTap">
    <text wx:if="{{!item.hidden && item.num > 0}}">{{item.num}}</text>
  </view>
</view>
```

`computedRows[i] = Math.floor(i / 7)`, `computedCols[i] = i % 7` 在 JS 中预计算好。

### 4.4 result 页

```
数据：
  level, time (秒), errors

星级计算：
  0 次错误 → 5 星（excellent）
  1 次错误 → 4 星（good）
  2~3 次错误 → 3 星（good）
  4 次以上 → 2 星（effort）

显示：
  - 关卡编号（"第 N 关"）
  - 星级评分 + 语录（参考 movingBlocks QUOTES 模式）
  - 用时
  - 错误次数
  - 正确率（level / (level + errors) * 100%）

按钮：
  - 再玩一次（onRetry → navigateBack + game.onRestart）
  - 下一关（onNext → navigateBack + game.onNextLevel）
  - 分享（open-type="share"）
```

## 5. 音效与震动

与 sudoku 使用 `wx.createWebAudioContext()` 生成音调的模式一致：

| 事件 | 音调 | 时长 | 震动 |
|------|------|------|------|
| 正确点击 | 880Hz 正弦波 | 120ms | 否 |
| 错误点击 | 220Hz 方波 | 200ms | `wx.vibrateShort({ type: 'medium' })` |
| 通关 | 523→659→784Hz 三连音 | 各 100ms | 否 |

设置项使用 `mg_settings`，字段名 `vibration`（与 `sd_settings` 一致）。

通过 `utils/settings-sync.js` 与全局开关联动。

## 8. 边界条件与体验注意事项

### 关卡 N=49 通关
- result 页的"下一关"按钮隐藏或替换为"全部通关"祝贺文案
- 可在 result 页显示特殊成就 UI

### 多 session 支持
- 每次进入游戏从 level 页选择关卡，不从上次中断处自动继续
- 但记录上一次达到的最高关卡，在 level 页高亮提示

### 数据同步
- 未登录：仅本地存储
- 已登录：写入云端 + 清理本地缓存
- level 页：本地缓存立即渲染 → 云端异步更新 → 合并展示

### 广告集成
- result 页展示插屏广告（与 movingBlocks result 页一致）
- result 页底部贴片 banner 广告
- level 页底部贴片 banner 广告

### UI 适配
- 7×7 格子大小 = `Math.floor((屏幕宽度 - 32px 留白) / 7)`
- 大屏（平板）适配：最大格宽 60px，居中显示
- 数字字号随格宽自适应
